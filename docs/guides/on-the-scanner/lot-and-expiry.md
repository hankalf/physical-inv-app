# On the scanner — A lot code or an expiry date

**Role:** Everyone counting on a full count  **When:** the count asks for a lot code or an expiry date as well

Some counts ask for the lot and the expiry on each pallet. Both can be missing on a real pallet, so both can be skipped.

## What you see

*On these counts the steps say* Scan LOT CODE *and* Enter EXPIRY (YYYY-MM-DD) *after the quantity.*

## What to do

1. **Scan LOT CODE**: scan the lot barcode on the pallet label, or type it. No lot on the label: tap **Skip**.
2. A lot different from the report shows a yellow message, *The report says this pallet is lot …*. Check you scanned the lot, then carry on.
3. **Enter EXPIRY (YYYY-MM-DD)**: type the date, for example 2027-03-15. No date: tap **Skip**.
4. A date that has passed shows *That date has passed — flag it to a supervisor*. Tell your lead.

## What the office sees

The lot and expiry on each line. A lot that does not match the report, and an expired date, are flagged on the pallet report.

## Do not

- Do not scan the pallet label or the rack label into the lot box: the scanner refuses it.
- Do not make up a date.
