Scanners each scanner gets its own link — open it once on the device and add it to the home screen

On the device: open the link in Chrome (or scan the QR into the address bar), then menu → Add to Home screen. Opening the link signs that scanner in — the server accepts counts from signed-in scanners only. Treat a link like a key: Reset link issues a new one and kills the old, and removing a scanner stops it entirely. A link used more than once is flagged, which is normal after a scanner is wiped and worth a look otherwise.

Aisles & racking blocks

Aisles in the same block share racking, so only one team can be active in a block at a time. Pair them automatically, or type a block name on any row.

Team assignments

Queue aisles per team in counting order, with the levels that team's equipment covers (A–C on foot, D–F with the lift, A–F for all). Levels are required. Two teams can share an aisle on different levels. A team's next aisle waits while another team holds those levels in its racking block — that is what staggers them.

Second counts

A second count is a bin somebody goes back to. They are raised automatically when a first count disagrees with the inventory report (quantity differs, wrong bin, not on the report, counted twice), when an aisle is handed back with expected pallets nobody saw, or by hand here. The counter is told the bin and the reason type, never the numbers, and the team that did the first count is never offered the second. Lines from a second count replace the first for that bin.
